# NCMMSC 2026 · 晚宴抽奖

纯静态网页，无需安装依赖，无后端和外部 CDN。所有字体、图形、动画均由浏览器本地绘制。

## 本地启动

在本目录打开终端：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 http://127.0.0.1:8080 。停止服务按 Ctrl+C。也可双击 index.html；为保证保存记录的行为一致，推荐使用本地服务。

## 现场使用

1. 抽奖池固定为 registration-ids.js 中的 660 个有效注册号，无需设置上限或上传文件。名单已剔除志愿者及组委会，缺号不会补入。
2. 填写本批新增名额 K。界面会显示 K + 上批待补名额。默认 K=5，后续只补抽时填 0。
3. 点击“开始抽奖”，再点击“停止并揭晓”。
4. 人工核实是否在场，点击缺席号码进行标记；再次点击可取消标记。
5. 点击“确认本批”，其余号码全部进入中奖名单；两类号码都永久退出本场号码池。
6. 后续批次自动加上缺额。若应抽人数大于剩余人数，可调整 K，或点击“抽完剩余号码”。未填满的名额会继续保留。

例：新增 10 人、缺席 2 人；下一批新增 5 人，抽取 7 人；若其中缺席 1 人，再下一批待补为 1。

使用右上角进入全屏；名单可折叠。默认静音，遵循系统“减少动态效果”设置。重置整场需要再次确认，重置后记录无法恢复。

## 数据与随机性

- 使用 crypto.getRandomValues、拒绝采样和部分 Fisher–Yates 洗牌，均匀不放回抽样。动画使用的随机值只用于视觉展示。
- 真实结果在动画开始前保存，刷新时恢复同一批次，不重新抽签。
- 使用当前浏览器当前站点的 localStorage。应在同一设备、同一浏览器、同一网址（含端口）完成整场；不支持跨设备同步。浏览器清理站点数据会清空记录。请仅打开一个操作页面。
- 保存失败会阻止状态推进，损坏数据不会被自动覆盖。跨标签页检测到变化后需刷新。
- 此工具面向主持人本地操作；浏览器中的数据可以被操作者修改，不提供服务端审计或防篡改证明。

## 验证

安装 Node.js 后运行 `node --test core.test.cjs registration-ids.test.cjs`，验证抽样、名额结转、边界输入和状态恢复。

`browser.test.cjs` 使用 Playwright 验证实际页面流程、刷新恢复、重复点击、响应式布局及减少动画。运行前启动本地服务，并确保 Playwright 与 Chromium 可用。测试使用隔离浏览器上下文，不修改现场浏览器记录。

## 固定抽奖池

registration-ids.js 仅包含 660 个注册号数字，不含姓名、单位或原始 CSV。界面不提供注册号上限或名单导入功能。修改名单需编辑此文件并重新部署。

与固定名单一致的历史活动继续恢复，待确认的抽奖结果保持不变；未开始的旧活动自动使用固定名单。已开始且号码池不同的旧活动会保留记录并暂停操作，需手动重置整场后使用固定名单。重置会清空旧中奖、缺席和批次记录。
